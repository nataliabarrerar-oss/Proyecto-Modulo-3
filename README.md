Proyecto-Módulo-3
Rindiendo Facil, es una aplicación para poder calcular el kilometraje realizado por vendedor, en cuanto a las visitas de cliente, permite registrar rápidamente la visita por cliente y al indicar la comuna visitada, devuelve los kilómetros recorridos en cada visita, también es posible generar un reporte simple y fácil de ver.
